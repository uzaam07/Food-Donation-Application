# 🍱 Food Donation Application

## 📖 About the Project

The **Food Donation Application** is an Android application developed to help reduce food wastage by connecting people who have surplus food with individuals or organizations in need.

The application provides a simple and user-friendly platform where donors can list available food, while receivers can browse nearby donations and request them. Firebase is used for user authentication and data storage, while Google Maps helps users locate food donations based on their current location.

This project was developed as part of my academic learning to gain practical experience in Android development, Firebase integration, and real-time database management.

---

## ✨ Features

- 👤 User Registration & Login using Firebase Authentication
- 🍛 Donate Surplus Food
- 📍 View Nearby Food Donations on Google Maps
- 📦 Request Available Food
- 📜 Donation History
- 👤 User Profile Management
- ⚙️ Settings Screen
- 🔄 Real-time Data Synchronization using Firebase
- 📱 Simple and Easy-to-Use Interface

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/uzaam07/food-donation-application.git
```

### Open the Project

Open the project using **Android Studio**.

### Configure Firebase

1. Create a Firebase project.
2. Enable Firebase Authentication.
3. Enable Firebase Realtime Database.
4. Download the `google-services.json` file.
5. Place it inside the `app/` directory.

### Run the Application

- Connect an Android device or start an emulator.
- Click **Run** in Android Studio.
